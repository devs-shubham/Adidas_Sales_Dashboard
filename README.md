👟 Adidas Sales Analysis Dashboard – Power BI
📌 Project Title

Adidas Sales Analysis Dashboard using Power BI

📖 Short Description / Purpose

This project is an interactive Power BI dashboard created to analyze Adidas sales performance across different regions, states, products, retailers, and time periods.

The dashboard transforms sales data into meaningful visual insights to help understand revenue, operating profit, units sold, pricing, profit margins, and sales trends.

The main purpose of this project is to demonstrate how Power BI, data visualization, and business analytics can be used to analyze sales performance and support data-driven decision-making.

🛠️ Tech Stack
Power BI – Dashboard development & visualization
Power Query – Data cleaning and transformation
DAX – Calculated measures and KPIs
Microsoft Excel / CSV – Data source
Data Visualization – Charts, maps, cards, slicers and filters
